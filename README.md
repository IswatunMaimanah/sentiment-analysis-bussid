# 🚌 Sentiment Analysis of Bus Simulator Indonesia (BUSSID) User Reviews

## 📌 Overview

This repository contains my undergraduate thesis project on sentiment analysis of user reviews from the **Bus Simulator Indonesia (BUSSID)** application.

A total of **19,482 user reviews** were collected during the data scraping stage. After data cleaning and preprocessing, **18,356 reviews** remained as the final dataset used for sentiment analysis.

The project applies **Natural Language Processing (NLP)** and **Machine Learning** techniques to classify user reviews into three sentiment categories:

- 😊 Positive
- 😐 Neutral
- 😞 Negative

Three machine learning algorithms were compared:

- Support Vector Machine (SVM)
- Naive Bayes
- Logistic Regression

The research has also been published in the **SMATIKA Journal**.

---

## 🎯 Objectives

The objectives of this project are:

1. Collect user review data from the Bus Simulator Indonesia (BUSSID) application.
2. Clean and preprocess the collected review data.
3. Analyze the distribution of user sentiments.
4. Visualize frequently occurring words for each sentiment category.
5. Apply TF-IDF for text feature extraction.
6. Build and compare machine learning classification models.
7. Evaluate model performance using different train-test data splits.

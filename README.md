# 🚍 Sentiment Analysis of Bus Simulator Indonesia (BUSSID) User Reviews

## 📌 Overview

This repository contains my undergraduate thesis project on sentiment analysis of Bus Simulator Indonesia (BUSSID) user reviews using Machine Learning.

The research compares three machine learning algorithms:

- Support Vector Machine (SVM)
- Naive Bayes
- Logistic Regression

The study has been published in the **SMATIKA Journal**.

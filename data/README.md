# Dataset

This folder contains documentation related to the dataset used in this research.

## Dataset Source

The dataset consists of user reviews of the Bus Simulator Indonesia (BUSSID) application collected from the Google Play Store.

## Data Collection

The data was collected through a scraping process and subsequently processed through several stages, including:

1. Data collection
2. Data cleaning
3. Text normalization
4. Text preprocessing
5. Feature extraction using TF-IDF
6. Sentiment analysis
7. Data visualization
8. Machine learning modeling

## Dataset Availability

The complete dataset is not included in this repository due to data size and usage considerations.

The notebooks used for the data collection and analysis process are available in the `notebooks/` folder.
